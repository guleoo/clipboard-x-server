# Clipboard X Server 1.0.0

## Features

- **Channel-based clipboard sync:** Share text and images across devices through a self-hosted Server.
- **On-demand content:** Sync previews first and retrieve full content when needed, with upload and download progress.
- **Web interface:** Browse clipboard history, preview and copy content, manage channels, and publish text or images manually.
- **Device management:** Register devices, issue and rotate device-bound API keys, and display client-managed names and icons.
- **Retention controls:** Configure periodic cleanup and retention limits in the Web interface without affecting client-side history.
- **Language and time display:** Switch between English and Simplified Chinese and set a UTC display offset.
- **Deployment options:** Deploy with Docker, run from source, or use native packages for Linux, macOS, and Windows on amd64 and arm64, with optional TLS.

---

## 功能特性

- **按频道同步剪切板：** 通过自托管 Server，在设备之间共享文本和图片。
- **按需获取内容：** 先同步预览，需要时再获取完整内容，并展示上传和下载进度。
- **Web 界面：** 浏览剪切板历史、预览和复制内容、管理频道，以及手动发布文本或图片。
- **设备管理：** 登记设备、签发和轮换设备专属 API Key，并展示客户端维护的名称和图标。
- **保留策略：** 在 Web 界面配置周期清理与保留限制，不影响客户端本地历史。
- **语言与时间显示：** 支持英文、简体中文切换和 UTC 显示偏移设置。
- **多种部署方式：** 支持 Docker、源码启动，以及 Linux、macOS、Windows 的 amd64 和 arm64 原生程序包，并可启用 TLS。
