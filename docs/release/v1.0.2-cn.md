# Clipboard X Server 1.0.2

> [English](https://github.com/guleoo/clipboard-x-server/blob/v1.0.2/docs/release/v1.0.2-en.md)

## 更新日志

- 修复完整内容已就绪时，长文本详情仍只显示截断预览的问题。打开条目后会加载完整文本，供查看和复制。
- 打开按需传输的文本条目时自动请求完整内容，并在获取过程中或加载失败时显示反馈。
