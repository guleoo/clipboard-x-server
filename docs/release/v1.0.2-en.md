# Clipboard X Server 1.0.2

> [简体中文](https://github.com/guleoo/clipboard-x-server/blob/v1.0.2/docs/release/v1.0.2-cn.md)

## Changelog

- Fix long-text details showing only a truncated preview even when the full content is available. Opening an item now loads the complete text for viewing and copying.
- Request on-demand text content when opening an item and show feedback while fetching or when loading fails.
