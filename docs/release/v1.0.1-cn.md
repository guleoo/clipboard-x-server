# Clipboard X Server 1.0.1

> [English](https://github.com/guleoo/clipboard-x-server/blob/v1.0.1/docs/release/v1.0.1-en.md)

## 功能特性

- **简化启动：** 运行 `./clipboard-x-server` 即可执行数据库迁移并启动服务；可使用 `--config {path}` 指定配置文件，或使用 `--no-migrate` 跳过迁移。
- **Windows ZIP 发布包：** Windows amd64 和 arm64 发布包改为 `.zip`，Linux、macOS 保持 `.tar.gz`。

## 更新日志

- 设备页面不再显示已吊销的 API Key；全部 Key 吊销后显示空状态和“签发 Key”按钮，服务端记录仍然保留。
